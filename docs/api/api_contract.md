# Contrato de API

## Propósito

Definir el acuerdo verificable entre frontend y backend antes de que ambos módulos se desarrollen en paralelo.

## Información por endpoint

Registrar método, ruta, propósito, parámetros, unidades, esquema de respuesta, códigos de estado, errores, ejemplos, autenticación, procedencia de datos, cobertura y semántica de valores faltantes.

## Estado

El contrato versionado está en [REST_CONTRACT_V1.md](REST_CONTRACT_V1.md). Este archivo queda como plantilla histórica. El frontend debe leer el REST CONTRACT, no esta plantilla.
