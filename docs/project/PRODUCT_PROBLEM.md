# Problema

## Propósito

Definir y justificar el problema u oportunidad que ATLAS atenderá, alineado con el reto y la temática oficial.

## Información por registrar

Contexto, población o proceso afectado, causas, consecuencias, alcance, evidencia cualitativa y cuantitativa, fuentes y situación actual. La versión para la memoria técnica tendrá un máximo oficial de 200 palabras.

## Decisión consolidada

ATLAS atiende la dispersión de información territorial, la dificultad de comparar ubicaciones y la interpretación de condicionantes según el tipo de obra. La necesidad elegida es identificar condicionantes antes de construir. La redacción para la memoria aún debe sustentarse con evidencia cualitativa y cuantitativa y respetar el máximo oficial de 200 palabras. Consulte `ATLAS_PLAN_MAESTRO.md`, `DECISIONS_FINAL.md` y el checklist oficial.
