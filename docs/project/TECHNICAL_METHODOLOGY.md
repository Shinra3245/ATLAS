# Metodología de desarrollo ejecutada

Se aplicó desarrollo incremental mediante contratos entre datos, motor y API.
Primero se inventariaron los libros recibidos y se calcularon hashes para
conservar originales y copias raw. Se normalizaron identificadores, campos y
nulos, verificando 755 localidades de Irapuato y Celaya. La serie climática y
los indicadores municipales se mantuvieron separados del maestro, según su
resolución y limitaciones.

El motor genera condiciones explicables, fuentes, cobertura y aspectos a
revisar. El tipo de obra modifica prioridades, conservando los datos base.
La comparación utiliza criterios comunes sin puntuación global ni ganador.
La API valida solicitudes y resultados contra contratos formales.

La verificación incluye reconstrucción determinista, integridad de originales,
pruebas automatizadas y solicitudes HTTP reales para los tres tipos de obra.
Los resultados fechados se guardan en los reportes de evidencia.

Las capas espaciales faltantes, la validación con especialistas y las pruebas
con usuarios permanecen pendientes. ML continúa desactivado. La interfaz se
desarrolla en otra sesión y requiere validación de su recorrido completo.
