# Decisiones consolidadas de ATLAS

## Propósito

Centralizar únicamente acuerdos ya establecidos por el equipo y distinguirlos de decisiones todavía abiertas. La definición extensa y sus implicaciones se encuentran en `ATLAS_PLAN_MAESTRO.md`.

## Decisiones aprobadas

| ID | Tema | Decisión consolidada |
|---|---|---|
| DF-01 | Problema | Integrar la dispersión de información territorial, la dificultad de comparar ubicaciones, la interpretación según tipo de obra y el uso de datos o ML solo cuando sea validable. |
| DF-02 | Usuarios principales | Despachos de arquitectura e ingeniería, desarrolladores inmobiliarios, gobiernos municipales o áreas de planeación, y profesionales u organizaciones vinculadas a proyectos urbanos. Constructoras pequeñas y medianas son clientes secundarios. |
| DF-03 | Necesidad | Identificar condicionantes territoriales antes de construir. |
| DF-04 | Propuesta de valor | Transformar datos territoriales oficiales en una evaluación preliminar integrada, explicable y comparable. |
| DF-05 | Diferenciación | Sistema de apoyo a decisiones complementado por una ficha de prefactibilidad; no sustituye un Atlas de Riesgos ni un dictamen técnico. |
| DF-06 | Tipos de obra | Vivienda, edificación y carretera o vialidad. |
| DF-07 | Alcance geográfico | El MVP cubre únicamente Irapuato y Celaya. Guanajuato estatal se considera expansión futura. |
| DF-08 | Factores núcleo | Inundación, fallas o fracturas, pendiente, susceptibilidad de laderas y uso de suelo; elevación como variable auxiliar. Otros datos útiles no se convierten automáticamente en riesgo. |
| DF-09 | Resultado | Ficha de evaluación territorial preliminar con condiciones, fuentes, cobertura, faltantes y aspectos a revisar. |
| DF-10 | Flujo y MVP | Mapa, tipo de obra, análisis individual, ficha, fuentes y comparación A/B bajo los mismos criterios. No habrá ganador automático. |
| DF-11 | Papel de ML | Complementario y explicable para una amenaza específica. El análisis SIG es el núcleo obligatorio y el sistema debe funcionar sin ML. |
