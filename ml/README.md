# Machine Learning

## Propósito

Reservar un espacio reproducible para explorar ML solo cuando los datos permitan formular y validar un problema defendible. El MVP debe poder funcionar sin ML.

## Información por registrar

- pregunta y variable objetivo;
- unidad de observación, etiquetas y procedencia;
- preprocesamiento y características;
- particiones que eviten fuga espacial o temporal;
- baseline, métricas, resultados, incertidumbre y limitaciones;
- versiones, semillas y artefactos reproducibles.

## Compuerta obligatoria

**PENDIENTE DE DECISIÓN DEL EQUIPO:** papel de ML, variable objetivo, datasets y estrategia de validación. No entrenar ni elegir un algoritmo final antes de resolverlo en `../docs/project/DECISIONS_FINAL.md`. Consulte las reglas científicas de `../docs/project/PROJECT_CONTEXT.md`.
